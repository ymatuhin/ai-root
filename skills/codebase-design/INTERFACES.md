# Варианты интерфейса

Методика для существенного выбора интерфейса; общий словарь — в [SKILL.md](SKILL.md).

1. Зафиксируй ответственность модуля, ограничения, потребителей и зависимости; при выборе границ используй [DEEPENING.md](DEEPENING.md).
2. Построй разумные разные варианты: минимальная поверхность интерфейса, удобство основного потребителя, расширяемость для подтверждённых сценариев. При доступности и пользе субагентов раздай им одинаковые факты и разные ограничения; иначе проработай варианты сам. Не придумывай варианты ради количества.
3. Для каждого покажи входы и результаты, ошибки, инварианты, порядок вызовов, пример использования и что скрыто в реализации. Назови стратегию зависимостей и границы проверок.
4. Сравни сложность для потребителя, локальность изменений и цену реализации. Рекомендуй вариант и обоснуй компромисс; передай вывод в design-plan или пользователю при самостоятельном запросе.

Результат — сравнение интерфейсов, без реализации и повторного выбора продуктового направления.
