# Changelog

Изменения относительно скиллов [Matt Pocock](https://github.com/mattpocock/skills) на коммите [`49dd158`](https://github.com/mattpocock/skills/tree/49dd158d1076134a641b33efb035946536778336).

## 2026-11-12

- Упрощён набор: implement-plan перенесён в implement/PLAN.md, design-options — в codebase-design/INTERFACES.md; отдельные команды удалены. Ссылки и каталог обновлены.
- design-plan выясняет существенные неизвестные без автоматического подробного интервью; grilling подключается по запросу пользователя.
- Для небольших изменений review-changes выполняет один общий проход без обязательного чтения четырёх методик, постоянных ID и формального бюджета раундов; исправления проверяются по затронутому поведению. Полный режим сохранён для сложных изменений и существенных рисков.
- В codebase-design объединение модулей зависит от их ответственности и пользы для потребителей; удаление старых тестов — от сохранения проверяемых сценариев. Уточнены условия введения интерфейсов и правила именования size.
- Для good-css зафиксирован источник vojtaholik/good-css на коммите `0790858e7ea466c49996ba01960565f7c89b6d82`, добавлены инструкция обновления и авторская лицензия MIT. CSS не изменён.
- Основные команды: explore, design-plan, implement и review-changes. implement сам подключает implement-plan для согласованного плана из нескольких задач; остальные навыки остаются доступны напрямую.
- В explore исследование, сравнение подходов и проверка сложности выполняются по необходимости. Из описаний убраны ролевые префиксы; в doubt снят лимит строк и обязательность таблицы для одной части решения.
- prototype завершается выводами и локальным артефактом без автоматической реализации, коммитов и трекера. В retro убрано разделение, откладывавшее соблюдение стандартов до ревью.
- Добавлен flow explore → design-plan → согласование → implement-plan, отдельные design-options, review-standards и review-spec.
- Добавлены review-bugs и simplify-code; code-review заменён оркестратором review-changes с единым контрактом diff и локальных изменений. Правила описания изменений перенесены в отчёт исполнителей.
- to-spec/to-tickets переименованы в write-spec/split-work с локальным результатом по умолчанию. grill-with-docs и implement-spec заменены design-plan и implement-plan.
- implement поддерживает одиночные задачи без обязательных трекера, коммита и полного набора ревью-субагентов. Субагенты в flow необязательны; конкретные Skill tool и MCP не требуются.
- brainstorm и doubt доступны оркестраторам; research и grilling работают без субагентов. Методика сравнения интерфейсов перенесена из codebase-design в design-options. TDD разрешает рефакторинг на зелёных тестах.
- Обновлены каталог и ссылки. Установщик сохраняет устаревшие ссылки этого checkout в резервной папке.
- prototype сохранён; разделения testing/tdd и domain-modeling/record-decision отложены, frontend-design не изменён.
- Удалён навык настройки проекта вместе с шаблонами трекеров. Спецификации и планы по умолчанию сохраняются в локальной `.scratch/<тема>/`.

## 2026-11-03

### Изменено

- `doubt` проверяет решение по частям и отвечает коротко: вердикт и таблица «оставить или выкинуть» для каждой части. Цена следующего изменения считается проблемой наравне с багом.

## 2026-11-02

### Добавлено

- `brainstorm` — найти разные подходы к задаче, начиная с «ничего не делать», и сравнить их цену и риски.
- `doubt` — проверить решение в субагенте до реализации: нужно ли оно и нет ли проще.

### Удалено

Не вызывались за 60 дней: `ask-matt`, `triage`, `wayfinder`, `to-questionnaire`, `wait-what`, `improve-codebase-architecture`, `wizard`, `grill-me` (дублировал `grilling`), `pr`, `diagnosing-bugs`.
