# Выбор подхода

Если неясна цель пользователя, задай один вопрос и жди ответа; факты о коде и окружении собирай сам.

1. Определи цель, ограничения и факты. Недостающее проверь по первоисточникам (код, доки, спецификации): 2+ независимых вопроса или широкий поиск при доступности субагентов по умолчанию отдавай параллельным read-only субагентам (`факты`, `путь:строки`, `пробелы`); одно место или без субагентов проверяй сам. Если выводы нужно сохранить отдельно и в проекте нет своей папки заметок, запиши в `.scratch/YYYY-MM-DD-<тема>/research.md`.
2. Если разумный подход один — кратко обоснуй его найденными фактами. Если есть разные по сути подходы (где живёт логика, что берём готовым, какую часть задачи закрываем), сравни их в таблице с опорой на код и документацию:
   - первый — «Ничего не делать» (что останется плохим, у кого и как часто);
   - второй — самый простой вариант, закрывающий основные случаи;
   - далее — только варианты, которые ты сам рекомендовал бы при конкретных условиях.

   | Подход | Суть | Что покрывает | Цена | Главный риск |
   | ------ | ---- | ------------- | ---- | ------------ |
   | Ничего не делать | | | | |

3. Если подход добавляет зависимости, абстракции или этапы сверх задачи, проверь его через [doubt](../doubt/SKILL.md). Оставшийся дорогой спорный вопрос, не закрытый `doubt`, при доступности субагентов по умолчанию передай на проверку предположений одному read-only субагенту без правок и вложенных.
4. Покажи рекомендацию с причинами, сравнение рассмотренных вариантов и оставшиеся неизвестные — без реализации.

Для продолжения в другой сессии сохрани итог в `.scratch/YYYY-MM-DD-<тема>/decision.md` (или в уже созданную папку темы в `.scratch/`). Если рекомендовано действие (не «Ничего не делать»), в конце выведи отдельным блоком одну команду для копирования (добавив `./.scratch/YYYY-MM-DD-<тема>/decision.md`, если файл сохранён):

- нужен пакет в `.scratch/` ([prepare](../prepare/SKILL.md)): `/prepare`
- локальная правка без плана ([implement](../implement/SKILL.md)): `/implement`
