# Выбор подхода

1. Определи цель и ограничения из запроса. Через [research](../research/SKILL.md) собери недостающие факты из кода и первичных источников. Независимые исследования можно выполнять параллельно при доступности субагентов, иначе последовательно.
2. Передай факты и ограничения в [brainstorm](../brainstorm/SKILL.md): сравни подходы.
3. Передай рекомендованный подход в [doubt](../doubt/SKILL.md). Учти найденную альтернативу, лишние части и неподтверждённые предположения; пересмотри рекомендацию при новых доказательствах.
4. Если после исследования и сравнения остаётся существенная неопределённость либо решение дорого переделывать, передай предварительную рекомендацию одному независимому агенту. Выбери модель по правилам консультаций в AGENTS.md. Передай цель, ограничения, факты, варианты и конкретный спорный вопрос; попроси проверить предположения, условия изменения выбора и более простой подход. Консультант работает без правок и своих субагентов. Проверь его возражения, при необходимости уточни исследование и рекомендацию. Для понятной локальной задачи пропусти консультацию.
5. Покажи подходы, рекомендацию с причинами и оставшиеся неизвестные. Результат — выбранное направление либо ясный выбор для пользователя, без реализации.

При продолжении с выбранным направлением используй design-plan. Handoff вызывается по запросу пользователя. При необходимости прототипа можно передать отдельный вопрос через handoff в prototype, а выводы вернуть в design-plan; прототип не становится production-кодом автоматически.
