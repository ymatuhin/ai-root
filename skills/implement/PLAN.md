# Выполнение плана

Дополнение к [implement](SKILL.md) для плана из нескольких задач.

1. Прочитай план, спецификацию и задачи; переиспользуй уже собранные в разговоре факты. Проверь критерии приёмки, зависимости и разрешение на выполнение. Если существенные решения ещё не согласованы, подготовь конкретный пакет через prepare; существующее разрешение используй без повторного запроса.
2. Выбери задачи, все зависимости которых завершены. Для каждой выполни реализацию, проверку новых имён и локальные проверки из [implement](SKILL.md) без общего ревью. При передаче исполнителю укажи цель, границы файлов, интерфейсы, критерии приёмки и нужный контекст прямо в задании (особенно при запуске в отдельном `worktree`, куда игнорируемая папка `.scratch/` не копируется).
3. Выполняй задачи последовательно либо параллельно по зависимостям. Субагенты и отдельные worktree нужны при пользе и доступности; без них работай сам в текущей папке. Назначь владельцев общих файлов или выполняй конфликтующие задачи последовательно.
4. Интегрируй результаты, проверь интерфейсы между задачами и приёмку плана. Незавершённая или упавшая задача сохраняет блокировку зависимых. Конфликты разрешай с учётом обеих задач; изменение согласованного контракта верни на согласование.
5. На общем результате выполни итоговое ревью, исправления и отчёт из [implement](SKILL.md). Выбирай режим ревью по всему изменению; в полном режиме веди один бюджет раундов на результат плана.

План завершён при выполненной приёмке; блокировку назови явно.
