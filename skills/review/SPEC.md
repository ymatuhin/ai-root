# Проверка требований

Используй переданный снимок и объём; если их нет, зафиксируй объём по [контракту изменений](CHANGES.md).

1. Найди требования в переданном документе, задаче или согласованных решениях разговора. При нескольких версиях установи актуальную. Недоступные требования не восстанавливай по коду.
2. Сверь каждое требование с реализацией и результатами проверок: выполнено, частично, не выполнено или не проверено.
3. Выводи только расхождения (частично, не выполнено, не проверено) и поведение вне согласованного объёма: требование и его источник, файл и строки проекта, расхождение и наблюдаемый эффект. Если расхождений нет, сообщи одной строкой «требования выполнены». Полную таблицу по всем требованиям строй только по прямому запросу.

Если требований нет, пропусти проход с явной причиной «нет требований для сравнения». Не меняй файлы.
