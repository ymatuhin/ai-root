name: brainstorm
description: Сравнивай подходы к задаче, когда решение ещё не выбрано; самостоятельный вызов или этап explore.
---

Задача — из аргумента или из разговора. Если неясна цель, задай один вопрос и жди ответа.

1. Изучи контекст: код проекта, возможности платформы, подключённые зависимости. Используй переданные факты; при прямом вызове собери минимально необходимые сам; у пользователя спрашивай только цели и ограничения.
2. Предложи подходы, разные по сути: где живёт логика, что берём готовым, какую часть задачи закрываем. Первый — «Ничего не делать»: что останется плохим, у кого и как часто. Следующий — самый простой, который закрывает основные случаи. Каждый подход — такой, который ты сам рекомендовал бы при каких-то условиях; если разумный подход один, так и скажи.

Готово, когда цена и главный риск каждого подхода опираются на найденное в коде и доках.

Ответ:

| Подход | Суть | Что покрывает | Цена | Главный риск |
| ------ | ---- | ------------- | ---- | ------------ |
| Ничего не делать | | | | |

**Рекомендация:** какой подход и почему. При самостоятельном вызове заверши рекомендацией и выбором для пользователя, без автоматического интервью. В explore передай сравнение и рекомендацию оркестратору для doubt.
