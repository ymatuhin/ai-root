# Проверка требований

Используй переданный снимок и объём; если их нет, зафиксируй объём по [контракту изменений](../review-changes/CHANGES.md).

1. Найди требования в переданном документе, задаче или согласованных решениях разговора. При нескольких версиях установи актуальную. Недоступные требования не восстанавливай по коду.
2. Для каждого требования укажи: выполнено, частично, не выполнено или не проверено. Подкрепи статус реализацией и результатами проверок; наличие кода само по себе не доказывает поведение во время исполнения.
3. Для замечания приведи требование и его источник, файл и строки реализации, расхождение и наблюдаемый эффект. Отдельно отметь поведение вне согласованного объёма.

Если требований нет, пропусти проход с явной причиной «нет требований для сравнения». Выдай покрытие требований и замечания, не меняя файлы.
