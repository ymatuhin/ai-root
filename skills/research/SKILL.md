---

Investigate directly, or delegate independent research when agents are available and useful. Without subagents, do the same work sequentially. Accept already collected facts and investigate only the remaining questions.

Process:

1. Investigate the question against **primary sources** (official docs, source code, specs, first-party APIs), not a secondary write-up of them. Follow every claim back to the source that owns it.
2. For research that needs a document, write the findings to a single Markdown file, citing each claim's source.
3. Save it where the repo already keeps such notes; match the existing convention, and if there is none, put it somewhere sensible and say where.

Distinguish observations, inferences and unknowns. Finish when the question has evidence-backed answers or explicit limits. Return the findings path when a document was created; a short lookup may be returned directly to the orchestrator.
