# Общая рабочая папка

Этот репозиторий хранит общие правила и навыки агентов. Соседние проекты остаются самостоятельными: их файлы исключены из Git этого репозитория.

## Работа между проектами

- Общие правила находятся в `AGENTS_GLOBAL.md`; прочитай их, если они ещё не загружены как глобальные инструкции.
- Перед изменениями в проекте прочитай его `AGENTS.md` и `CLAUDE.md`, если они есть. Для вложенной папки учитывай инструкции по пути к ней.
- Выполняй Git-команды с явным каталогом: `git -C <проект> ...`. Перед коммитом проверь корень через `git rev-parse --show-toplevel`: у некоторых папок нет собственного репозитория.
- В задаче между проектами фиксируй изменения и запускай проверки отдельно для каждого затронутого репозитория.
- Корневой `.gitignore` скрывает проекты и от обычного поиска `rg`. Ищи внутри нужного проекта; при поиске из `Dev` используй `rg --files --hidden -g '!.git' --no-ignore-parent <проект>`.

## Изменение общей настройки

Редактируй источники в этом репозитории. После добавления навыка запусти `python3 scripts/install.py`. Скрипт сохраняет заменяемые файлы вне репозитория; повторный запуск не меняет уже правильные ссылки. Системные навыки и навыки плагинов обновляются своими приложениями.
